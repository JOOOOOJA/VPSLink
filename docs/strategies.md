# Стратегии winws

Если встроенный WARP не соединяется, откройте **«Стратегии»** и подберите обработку его TLS-запросов. По умолчанию доступны варианты из Flowseal/zapret-discord-youtube. VPSLink адаптирует совместимые TLS-параметры и шаблоны пакетов из этого каталога под свой канал WARP MASQUE через TCP/443. VPN-трафик направляет через VPS клиент AmneziaVPN.

## Как пользоваться

1. Выберите свой сервер в верхнем списке. Для него должен быть включён встроенный WARP.
2. Откройте «Стратегии». Шесть встроенных вариантов доступны без загрузки. Базовый сохраняет поведение 0.3.1.
3. Выберите источник **Flowseal · zapret-discord-youtube** или пример bol-van и нажмите **«Обновить с GitHub»**. Вы можете скачать каталог с работающим мостом и выбрать новую стратегию позже. Под каталогом посмотрите причины пропусков.
4. Перед проверкой или подбором отключите профиль AmneziaVPN, затем мост VPSLink. Если запущены внешний winws/zapret, системный WARP или другой usque, остановите их. Проверка запускается после остановки этих процессов и отключения активных адаптеров Amnezia и WARP. Если ваш удалённый сеанс зависит от VPN, подготовьте отдельный доступ. При отключении интернет может временно пропасть.
5. Запустите VPSLink от администратора и нажмите **«Проверить выбранную»** или **«Подобрать автоматически»**. Если хотите начать с Flowseal, выберите его вариант. Подбор пройдёт по списку с выбранной позиции, продолжит с начала и остановится на первом подтверждённом пути. На каждый вариант отводится до 25 секунд. Чтобы остановить запущенные проверкой процессы, нажмите **«Отменить проверку»**.
6. После успеха нажмите **«Использовать для сервера»**, подключите VPSLink и включите прежний профиль AmneziaVPN. Подбор подтверждает соединение до вашего VPS и совпадение SSH-ключа. После подключения отдельно проверьте рукопожатие VPN, интернет и DNS. Если оцениваете скорость или утечки, проверяйте их с включённым VPN.

Если выбранный вариант не подошёл, нажмите **«Вернуть базовую»**. Чтобы вернуть предыдущий набор вариантов, нажмите **«Предыдущий каталог»**. Сохранённая стратегия привязана к серверу. Выберите и примените другой вариант вручную, когда захотите его сменить.

Перед первым подбором выполните обычное подключение и подтвердите условия Cloudflare, чтобы зарегистрировать устройство WARP. Затем используйте эту регистрацию при проверке стратегий.

## Источник и ограничения импорта

Допустимые источники закреплены в коде:

- [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube): файлы `general*.bat` с ограниченными именами, ветка `main`. В списке сохраняются названия `general`, `ALT`, `FAKE TLS` и номер TLS-секции. Одинаковые наборы параметров объединяются; в пояснениях перечислены совпадающие файлы.
- [`bol-van/zapret-win-bundle`, `zapret-winws/preset1_example.cmd`](https://github.com/bol-van/zapret-win-bundle/blob/master/zapret-winws/preset1_example.cmd), ветка `master`.

В каталог входят варианты для legacy winws. При обновлении VPSLink скачивает параметры и шаблоны из одной ревизии выбранного источника. winws, WinDivert и usque входят в полную сборку VPSLink.

Клиент получает SHA коммита выбранной ветки. Для Flowseal через GitHub API читается дерево файлов этого коммита, затем BAT и необходимые шаблоны пакетов загружаются с `raw.githubusercontent.com` с тем же SHA в URL. Проверяются пути, тип, обычный файловый режим (не символическая ссылка), размер, UTF-8 для BAT и Git blob SHA-1 каждого файла. Для bol-van используется GitHub Contents API с закреплённым коммитом. Это контроль соответствия ответу GitHub, не независимая подпись автора. Перенаправления не принимаются; токен GitHub не нужен. Компрометация источника остаётся риском, ограниченным разрешёнными параметрами.

VPSLink читает BAT/CMD как данные. Импортёр берёт секции TCP/443 и проверяет параметры по списку разрешённых `--dpi-desync*` и `--ip-id=zero`. winws получает подготовленный VPSLink набор аргументов и фильтр для IPv4-адреса MASQUE из вашей регистрации WARP. Если секция содержит параметры захвата, `--new`, Lua или неизвестные параметры, проверьте причину пропуска этой секции под каталогом.

Ссылки на разрешённые `bin/tls_clienthello_*.bin` и `bin/stun*.bin` заменяются проверенными байтами в форме `0x...`, до 4096 байт на шаблон. Процесс не получает пути к загруженным файлам. Сохраняются последовательность нескольких TLS-шаблонов, модификаторы, перекрытие частей и другие разрешённые параметры. Предел — 24 аргумента и 24000 символов на стратегию. Шаблоны HTTP в смешанной секции также сохраняются, хотя транспорт VPSLink использует TLS.

Варианты с `--dpi-desync-fooling=ts` в этой версии пропускаются с пояснением: им требуется TCP timestamps. Служебный скрипт Flowseal включает этот параметр Windows, а VPSLink системные TCP-настройки не меняет. Пропуск действует и при уже включённых timestamps; поддержка таких вариантов требует отдельной проверки. Остальные несовместимые параметры также не удаляются ради получения формально рабочего варианта.

Фильтр захвата остаётся заданным VPSLink: исходящий IPv4 TCP, порт назначения 443, точный IP MASQUE. Параметры передаются через `ProcessStartInfo.ArgumentList`, без командной оболочки. SHA-256 исполняемых компонентов проверяется прежним механизмом приложения.

## Хранение и проверка

`winws-catalog.json` и предыдущий `winws-catalog.json.bak` хранятся рядом с профилями в `%LOCALAPPDATA%\ThingsNotFun-Link`. Сначала записывается и повторно проверяется временный файл, затем он атомарно заменяет каталог. Невалидный ответ или отсутствие совместимых секций сохраняют прежний каталог. При восстановлении повреждённый файл сохраняется отдельно, без затирания исправной резервной копии.

Профиль содержит собственный снимок выбранных параметров и версию источника. Загрузка нового каталога не меняет этот снимок и не перезапускает текущие процессы. Старые профили без нового поля используют базовую стратегию. Пароли, ключи и настройки ручного подключения при сохранении стратегии сохраняются.

Проверка использует только выбранную стратегию и встроенный WARP, а при настроенном HTTPS-шлюзе — этот шлюз поверх WARP. Другие транспортные пути не подставляются. SSH-пароль при проверке не используется, команды на VPS не выполняются; relay-токен применяется, если его требует настроенный шлюз. После каждого варианта собственные usque/winws завершаются. Для определения «лучшей по скорости» стратегии проверка не предназначена.

Автотесты покрывают ограничения импорта и фильтра, отказ при невалидном GitHub-ответе, сохранение профилей, откат, остановку перебора и отмену. Работоспособность конкретной стратегии зависит от провайдера и проверяется пользователем в его сети.
