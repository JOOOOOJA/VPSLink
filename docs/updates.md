# Обновления

Чтобы посмотреть доступные версии, откройте **Обновления**. VPSLink проверяет релизы `JOOOOOJA/VPSLink` в канале **Proof of Concept**, включая предварительные версии для тестирования.

Приложение получает до 20 последних публичных релизов GitHub и выбирает более новую числовую версию `X.Y.Z` (тег с `v` или без него), исключая drafts. Для стабильного канала в коде предусмотрен режим `/releases/latest`, не принимающий prereleases. Downgrade не предлагается.

VPSLink проверяет обновления при запуске и затем по таймеру. После успешной проверки следующая автоматическая проверка пройдёт не раньше чем через сутки. После ошибки VPSLink повторит попытку через 30 минут. Если хотите проверять версии вручную, выключите автопроверку и пользуйтесь кнопкой **Проверить обновления**. Настройки этой вкладки хранятся отдельно от VPN-профилей в `updates.json`.

В релизе нужен ровно один `VPSLink-X.Y.Z-Setup.exe`, размер не более 256 МиБ и GitHub `digest` SHA-256. Допустим только точный URL файла в закреплённом репозитории и HTTPS-перенаправления на разрешённые домены GitHub. При несовпадении размера/хеша установка блокируется, неполная загрузка удаляется.

1. Скачайте обновление при работающем соединении.
2. Отключите профиль в AmneziaVPN, затем мост VPSLink.
3. Нажмите **Установить и закрыть Link** и подтвердите запрос Windows. VPSLink повторно проверит Setup перед запуском. Установщик обновит текущую копию и сохранит ваши профили.
4. После установки откройте VPSLink, подключите мост и включите прежний профиль AmneziaVPN.

Если у вас ранняя локальная сборка 0.3.1 с пустым адресом репозитория, один раз установите публичный VPSLink Setup. После этого проверяйте новые версии во вкладке **Обновления**.
