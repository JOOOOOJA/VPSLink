# Обновления

Источник: `JOOOOOJA/VPSLink`. Эта версия использует явный канал **Proof of Concept**, включающий GitHub prereleases. Предварительный релиз не означает готовность к промышленной эксплуатации.

Приложение получает до 20 последних публичных релизов GitHub и выбирает более новую числовую версию `X.Y.Z` (тег с `v` или без него), исключая drafts. Для стабильного канала в коде предусмотрен режим `/releases/latest`, не принимающий prereleases. Downgrade не предлагается.

Проверка запускается вместе с окном и повторяется таймером; после успешной проверки — не чаще раза в сутки. Ошибки проверяются повторно через 30 минут. Автопроверку можно выключить, ручная кнопка доступна отдельно. Настройки лежат в `updates.json`, независимо от VPN-профилей.

В релизе нужен ровно один `VPSLink-X.Y.Z-Setup.exe`, размер не более 256 МиБ и GitHub `digest` SHA-256. Допустим только точный URL файла в закреплённом репозитории и HTTPS-перенаправления на разрешённые домены GitHub. При несовпадении размера/хеша установка блокируется, неполная загрузка удаляется.

Сначала пакет скачивается при работающем соединении. Затем пользователь отключает профиль AmneziaVPN, мост VPSLink и нажимает «Установить». Повторно проверенный Setup запускается с UAC. Он обновляет ту же установку, сохраняет данные пользователя и не перезагружает Windows автоматически. Автоматического отключения VPN или принудительной установки нет.

Первое подключение обновлений для ранней локальной сборки 0.3.1 требует один раз установить публичный VPSLink Setup: в старой локальной сборке адрес репозитория был пустым. Последующие более новые версии будут обнаруживаться приложением.
