# Данные и границы защиты

VPSLink — экспериментальная сборка, без независимого аудита. Защита зависит от доверия к Windows, вашему VPS, SSH-ключу, VPN-клиенту, Cloudflare и загружаемым компонентам.

## Локальные данные

- Профили хранятся в `%LOCALAPPDATA%\ThingsNotFun-Link\profiles.json` (старое имя сохранено для совместимости).
- Пароли/SSH-ключи, VPN-конфигурации и токены relay защищены Windows DPAPI текущего пользователя. Это защита хранения, а не защита от вредоносного процесса с правами того же пользователя или администратора.
- Регистрация usque находится в подкаталоге `WarpCore`. Её `config.json` содержит ключи устройства; он защищён ACL каталога, **не DPAPI**.
- Экспортированный VPN `.conf` содержит приватный ключ в обычном виде. Пользователь отвечает за его хранение и удаление.
- Резервные копии профилей содержат те же защищённые данные и тоже не должны публиковаться.
- Диагностика может содержать IP/домены сервера, публичные ключи, интерфейсы и пути. Она не предназначена для публикации без очистки.

## Сеть

Встроенное ядро создаёт собственную WARP-регистрацию с согласия пользователя; регистрация системного Cloudflare One не импортируется. Внешний транспорт использует инфраструктуру Cloudflare, которая видит соответствующие соединения и метаданные. Публичный IP выхода VPN — адрес вашего VPS при правильной настройке VPN/NAT, но сам по себе этот факт не доказывает отсутствие всех утечек.

VPSLink не реализует kill switch. IPv6, DNS и маршруты приложений зависят от AmneziaVPN и Windows. При отключении VPN приложения могут использовать обычную сеть. Внешний MASQUE endpoint намеренно исключён из VPN-маршрутов. Совместная работа нескольких VPN и фильтров не гарантируется.

Проверяйте отпечаток SSH через независимый доверенный канал. Автоматическое принятие неожиданно изменившегося ключа не предусмотрено. Наличие relay-токена не отменяет необходимость SSH-учётных данных.

## Обновления и компоненты

Источник обновлений закреплён в коде; произвольный сервер обновлений из профиля не принимается. Размер, HTTPS-адрес и SHA-256 проверяются до установки и перед запуском. SHA-256 подтверждает целостность относительно GitHub, но не заменяет подпись издателя. Компрометация официального аккаунта/release остаётся угрозой. Установщик пока без Authenticode-подписи автора.

WinDivert требует административных прав и загружает сетевой драйвер. Каталог стратегий из официального zapret обновляется как ограниченный набор данных: скачанные CMD не исполняются, фильтр остаётся ограниченным одним MASQUE-адресом и TCP 443. Снимок стратегии сохраняется отдельно для каждого сервера; обновление каталога не применяет его автоматически. [Механизм импорта, проверки и отката](strategies.md).

В репозиторий не включены рабочие профили, регистрации WARP, ключи, токены, настройки VPS, VM, личные журналы или история локальной разработки. Тестовые ключи — явные синтетические фикстуры, не рабочие учётные данные.
