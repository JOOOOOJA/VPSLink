# Приложения напрямую в VPSLink

Используйте этот экспериментальный режим, если Steam или игра должны выходить через провайдера, а браузер и другие приложения — через VPS. AmneziaVPN по-прежнему поднимает AmneziaWG. VPSLink запускает отдельный sing-box TUN для разделения новых TCP- и UDP-соединений по пути запускающего их `.exe`.

1. В разделе **Напрямую** откройте [официальный релиз sing-box 1.14.4](https://github.com/SagerNet/sing-box/releases/tag/v1.14.4). Скачайте `sing-box-1.14.4-windows-amd64.zip`. Нажмите **Выбрать ZIP…** и укажите архив целиком. VPSLink проверяет SHA-256 при импорте и при каждом запуске. sing-box не входит в дистрибутив VPSLink.
2. Выберите сервер и нажмите **Настроить список…**. Включите режим и отметьте Steam или добавьте нужные `.exe`. Опция Steam включает клиент, его дочерние программы внутри каталога Steam и `.exe` из `steamapps/common` подключённых библиотек Steam. Сторонние лаунчеры, игры и античиты вне этих каталогов можно добавить по точному пути.
3. Чтобы использовать готовый список из AmneziaVPN, выберите в ней режим «исключить приложения из VPN» и сохраните исключения. Затем выключите её встроенное разделение по приложениям и сайтам. Отметьте в VPSLink **Подхватывать список исключений AmneziaVPN при подключении**. VPSLink читает сохранённый список `ExceptApps` из текущей учётной записи Windows, включая выключенный режим разделения. Список перечитывается при каждом запуске прямого маршрута. Поддерживаются абсолютные пути к `.exe`; записи только с идентификатором пакета Windows пропускаются. Списки «только через VPN» не преобразуются в исключения.
4. Для прямого режима выключите KillSwitch в AmneziaVPN и переподключите её профиль при необходимости. Встроенные фильтры Amnezia блокируют трафик через отдельный TUN. С выключенным KillSwitch при потере VPN Windows может использовать обычный маршрут провайдера. Если такое поведение неприемлемо, оставьте прямой режим выключенным.
5. Подключите VPSLink, затем основной полный профиль в AmneziaVPN. В разделе **Напрямую** дождитесь статуса «Прямой маршрут включён». Перезапустите выбранные приложения, чтобы их старые сокеты не продолжали использовать прежний путь.

VPSLink не изменяет настройки AmneziaVPN. Чтобы вернуться к обычной схеме, отключите VPN и мост, снимите флажок прямого маршрута в профиле VPSLink, восстановите нужные настройки AmneziaVPN и подключитесь снова.

## Как устроено

- Режим выключен в новых и существующих профилях по умолчанию. Приглашения не содержат локального списка приложений. Профиль хранит настройки выбора, а официальный архив хранится отдельно в каталоге данных VPSLink.
- После подтверждения свежего VPN-рукопожатия и обмена UDP VPSLink определяет внешний шлюз и интерфейс `AmneziaVPN`. Нужны права администратора, один работающий внешний шлюз, полный профиль IPv4 и отсутствие маршрута IPv6 по умолчанию. Ограниченный тестовый профиль с `1.1.1.1/32` не подходит.
- VPSLink делит широкие маршруты IPv4 AmneziaVPN на более конкретные префиксы для `VPSLink-Direct`. Loopback, локальные сети, имеющиеся внешние `/32`, адрес встроенного WARP и адреса открытых SSH-сеансов исключаются из перехвата. Остальные захваченные соединения направляются в интерфейс AmneziaVPN. Правила не переносят настройки DNS из Amnezia.
- Компонент завершается вместе с мостом, при обнаружении изменения маршрутов или конфликта настроек. После изменения сети проверяйте VPN и используйте **Повторить запуск**. При выходе из VPSLink Windows Job Object останавливает дочерний процесс, а sing-box освобождает свой TUN.
- При несовместимом формате реестра добавьте нужные приложения вручную. При запуске игр из других библиотек проверьте, где находится фактически работающий `.exe`. Правила определяют маршрут по пути к процессу, а не по тому, кто его запустил.

## Проверка

На прототипе с этой схемой маршрутизации наблюдались прямые TCP и UDP соединения Steam и Deadlock. В десятиминутном тесте игрок сообщил, что загрузился в матч. Steam Cloud завершил синхронизацию после выхода с `result OK`. Обычный IPv4 HTTPS-запрос продолжал выходить через VPS. Это проверка одного ПК, одного провайдера и одной игры. Разные античиты, сторонние лаунчеры, IPv6 и различные версии AmneziaVPN требуют отдельной проверки.

Если матч не загружается, сначала проверьте статус прямого маршрута и после его запуска перезапустите игру и Steam. Затем сравните попытку с обычным прямым подключением, учитывая, что для него потребуется отключить VPN. В отчёте укажите версию Windows, AmneziaVPN, игры, способ выбора правила и точное сообщение об ошибке.

Разбор ограничений прежнего механизма: [Mullvad Windows split tunnel](https://github.com/mullvad/win-split-tunnel#localhost-udp-communications) и [отчёт Amnezia о Deadlock](https://github.com/amnezia-vpn/amnezia-client/issues/1320). Формат правил и TUN: [sing-box route rules](https://sing-box.sagernet.org/configuration/route/rule/) и [sing-box TUN](https://sing-box.sagernet.org/configuration/inbound/tun/).
