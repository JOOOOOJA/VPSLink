# Проверка VPSLink 0.5.1

## Сравнение на одном стриме Discord

Проверка выполнена 17 ноября 2026 года на одном ПК с Windows, одним профилем AmneziaWG и одним VPS. Один и тот же входящий стрим Discord оставался открытым либо возобновлялся после переключения. Сначала проверялся WARP + HTTPS, затем прямой QUIC DATAGRAM. Перед каждым замером и после него подтверждались транспорт и HTTPS-выход через VPS.

Для каждого пути измерили просмотр со стримом, два скачивания по 6 МиБ и две отправки по 3 МиБ. Во время проверки отправлялись ICMP-пробы на два контрольных адреса через VPN. Скорость посчитана по сумме байтов успешных HTTPS-передач и их длительности. Среднее и максимум RTT рассчитаны по полученным ответам обеих целей. Пропуск означает отсутствие ответа за 1,2 секунды.

| Показатель | WARP + HTTPS | Прямой QUIC |
|---|---:|---:|
| Скачивание, Мбит/с | 27,6 | 18,5 |
| Отдача, Мбит/с | 6,5 | 7,9 |
| Только стрим, средний / пик RTT, мс | 81,7 / 250 | 88,2 / 99 |
| Дополнительное скачивание, средний / пик RTT, мс | 126,0 / 268 | 105,5 / 144 |
| Дополнительная отдача, средний / пик RTT, мс | 270,6 / 813 | 220,7 / 406 |
| Пропуски при скачивании | 0 из 38 | 1 из 52 |
| Пропуски при отдаче | 4 из 76 | 4 из 62 |

Это короткие последовательные замеры на одном подключении. Скорость и задержка могут меняться в зависимости от провайдера, нагрузки и доступности маршрутов. Пропуски показывают таймауты ICMP-проб. Для оценки медиатрафика Discord нужны отдельные метрики RTC и более длинный повторный тест.

## Резервный маршрут

Режим «Авто» проверен при недоступном UDP на старте и при остановке QUIC-модуля после подключения. При сквозной проверке с активным AmneziaWG первые ответы контрольных адресов вернулись примерно через 4,1 секунды после остановки QUIC. Локальный порт и IP выхода сохранились. По наблюдению пользователя Discord восстановился без переподключения AmneziaVPN.
