Link помогает добраться до вашего VPS, когда обычное соединение недоступно. AmneziaVPN направляет через него интернет-трафик.

Ваш компьютер→Link→Ваш VPS→Интернет
Для работы нужны собственный VPS с уже настроенным AmneziaWG и установленная AmneziaVPN, совместимая с версией VPN на сервере. Link может создать отдельного клиента VPN; установка AmneziaWG на пустой VPS пока не выполняется.

Что нужно заранее и где это взять

Минимальный набор: компьютер с Windows, свой VPS с работающим AmneziaWG, данные доступа к серверу и приложение AmneziaVPN. Для собственного постоянного шлюза дополнительно нужны домен и аккаунт Cloudflare.

Обязательно для подключения

1. Компьютер с Windows 11 x64 и интернетом

Нужна учётная запись с возможностью подтвердить права администратора: их запрашивает встроенный сетевой компонент Link. Windows на ARM в этой сборке не поддерживается. Обычного домашнего интернета достаточно; телефон, USB-модем и виртуальная машина нужны только для отдельных испытаний.

Установщик Link включает usque и winws, а также установщик .NET Desktop Runtime. Отсутствующий OpenSSH Client он получает через Центр обновления Windows. Для этого требуется доступ к сервису обновлений.

2. Собственный VPS — сервер в интернете

VPS, или VDS, — арендуемый виртуальный компьютер, который остаётся включённым у хостера. Он станет точкой выхода вашего VPN. Ищите услугу «VPS/VDS», с доступом администратора и публичным IPv4-адресом.

Ориентир для заказа: KVM, архитектура x86-64/amd64, Ubuntu 24.04 LTS. На этой системе проверялся Link. По требованиям Amnezia нужны как минимум 1 ядро CPU, 1 ГБ RAM и 10 ГБ диска; это минимум для VPN, а не гарантия скорости Link. Для совместной работы VPN и шлюза разумно оставить запас ресурсов.

Где взять: у VPS-хостера. Начать можно с инструкции Amnezia по выбору и заказу сервера, где есть пример Amnezia Hosting. Другой провайдер тоже подходит, если выполняет требования. До оплаты уточните доступность SSH, наличие консоли в личном кабинете, лимит трафика, скорость порта, допустимость личного VPN и подходящий способ оплаты. Обычный хостинг сайта или купленная VPN-подписка сами по себе не дают такого сервера.

3. Доступ к VPS и работающий AmneziaWG

Подготовьте IP сервера, порт SSH, логин и пароль либо приватный SSH-ключ. Обычно эти данные выдаёт хостер в личном кабинете или письме после создания VPS. Отпечаток SSH сверяйте через консоль хостера. Для постоянного шлюза в текущем Link нужны Linux x64 с systemd, Python 3.8+ и вход с правами root.

На VPS должен быть уже установлен AmneziaWG. Если сервер пустой, сначала настройте его через AmneziaVPN в режиме Self-hosted по официальной пошаговой инструкции. После этого Link сможет создать отдельного VPN-клиента. Сам Link пока не устанавливает AmneziaWG на пустой сервер.

Если прямой SSH заблокирован, для первого развёртывания всё равно нужен работающий путь управления: через встроенный WARP, заранее подготовленный шлюз или другую доступную сеть. Консоль хостера помогает вручную подготовить сервер, но Link не подключается к ней автоматически. Один только домен не решает проблему первого входа.

4. AmneziaVPN на вашем компьютере

Скачайте клиент для Windows с официальной страницы AmneziaVPN. Версия должна поддерживать AmneziaWG, установленный на вашем VPS: например, для AWG 3.1 нужна соответствующая поддержка клиента. Приложение устанавливается отдельно от Link.

Link подготавливает путь до сервера и файл профиля. AmneziaVPN импортирует этот файл и направляет через VPN трафик приложений. При ежедневной работе обе программы остаются запущенными; для настройки своего сервера выбирайте Self-hosted.

Дополнительно — для постоянного шлюза

5. Свой домен

Домен — имя вроде example.com. Для режима «Постоянный шлюз» Link нужен домен, которым вы управляете. Если до VPS уже работает другой сохранённый путь, домен для такого подключения не обязателен.

Где взять: зарегистрировать у регистратора, например REG.RU или Cloudflare Registrar. Можно использовать уже имеющийся домен. Домен и VPS разрешается держать у разных компаний. При выборе смотрите не только цену первого года, но и стоимость продления.

В Cloudflare добавляется example.com, без https:// и www.. Для Link выберите свободный поддомен, например link.example.com: покупать его отдельно не нужно. Для самого шлюза не требуются сайт, почтовый ящик на домене или отдельный хостинг сайта.

6. Аккаунт Cloudflare и активный домен в нём

Создайте аккаунт в панели Cloudflare, добавьте свой домен и выполните инструкцию подключения домена. Перенесите необходимые DNS-записи, затем у регистратора укажите именно те NS-серверы, которые Cloudflare назначил вашему домену. Дождитесь статуса Active.

Регистрация домена может остаться у прежней компании: Cloudflare будет управлять его DNS. Если на домене уже есть сайт или почта, сохраните их записи перед сменой NS. Покупка домена и изменение записи A сами по себе не активируют домен в Cloudflare.

7. API-токен для первоначальной настройки

Создайте его в аккаунте Cloudflare. Он разрешает Link создать туннель и DNS-запись; VPS-хостер этот токен не выдаёт. Нужны только права и область доступа, описанные в разделе «Постоянный шлюз». Вставьте токен в окно настройки Link. После успешной настройки для обычных подключений этот API-токен уже не нужен.

Что не требуется готовить отдельно

В комплекте уже есть ядро WARP и winws. Для встроенного режима не нужно отдельно устанавливать Cloudflare One Client или zapret: Link запускает свои компоненты. Отдельное устройство WARP регистрируется при первом подключении с вашим подтверждением. Промежуточный VPS и оплаченная VPN-подписка для описанной схемы не нужны.

Перед нажатием «Подключить»: VPS оплачен и включён; данные SSH под рукой; AmneziaWG на сервере работает; AmneziaVPN установлена. Для постоянного шлюза дополнительно готовы домен Active, свободный поддомен и ограниченный API-токен. Доступность выбранного пути зависит от вашей сети: Link не гарантирует обход любой блокировки.

Ссылки на сервисы — примеры и официальные инструкции, а не гарантия их доступности или рекомендация конкретного тарифа. VPS обычно оплачивается регулярно, домен — при регистрации и продлении. Условия оплаты и цены проверяйте перед заказом. Ссылки проверены 14 ноября 2026 года; для их открытия нужен интернет.

Первое подключение

  1. Установите и откройте Link

    Запустите установщик. Он установит приложение, встроенное ядро WARP и winws. Если необходимые компоненты Windows отсутствуют, установщик сообщит об этом и предложит их подготовить. Для подключения со встроенным ядром Windows запросит права администратора.

  2. Добавьте сервер

    Откройте «Серверы» → «Добавить сервер». Введите адрес VPS, имя пользователя и пароль SSH или выберите файл ключа. Оставьте «Создать профиль на VPS», если отдельного VPN-профиля ещё нет. Если профиль уже есть, выберите импорт .conf.

    При первом входе сверьте отпечаток SSH с консолью или панелью хостера. Если он неожиданно изменился, сначала выясните причину.

  3. Дождитесь готовности сервера

    На главной нажмите «Подключить». При первом использовании встроенного WARP подтвердите отдельную регистрацию Cloudflare и её условия. Когда появится «Сервер готов», Link установил мост до вашего VPS.

  4. Импортируйте профиль один раз

    В разделе «Серверы» нажмите «Сохранить профиль VPN…». В AmneziaVPN выберите импорт из файла, укажите сохранённый .conf и подключитесь. Для AWG 3.1 нужен клиент с поддержкой этой версии.

  5. Проверьте интернет

    Вернитесь на главную Link и нажмите «Проверить интернет». Приложение выполнит HTTPS-запрос через VPN и покажет внешний IP. Он должен соответствовать выходу вашего VPS. Само сообщение «VPN отвечает» ещё не доказывает доступ в интернет.

На каждый день

Подключение

Откройте Link, выберите сервер и нажмите «Подключить». После готовности включите ранее импортированный профиль в AmneziaVPN. Повторный импорт и API-токен Cloudflare не нужны.

Сворачивание и отключение

Свёрнутое окно Link продолжает работать в области уведомлений. Для полного отключения сначала выключите VPN в AmneziaVPN, затем нажмите «Отключить» в Link. Через значок в области уведомлений можно открыть окно или выйти.

Не включайте одновременно исходный VPN-профиль и его копию с тем же ключом. Для отдельного устройства лучше создать отдельного клиента.

Постоянный шлюз

Нужен, если прямой адрес VPS недоступен, а временный HTTPS-адрес меняется после перезапуска. Постоянный шлюз использует поддомен в вашем аккаунте Cloudflare.

  1. Подготовьте домен

    Добавьте свой домен в Cloudflare, сохраните нужные DNS-записи и дождитесь статуса Active. Выберите свободный поддомен, например link.example.com.

  2. Создайте ограниченный API-токен

    Права: Account / Cloudflare Tunnel / Edit; Zone / DNS / Edit; Zone / Zone / Read. Ограничьте его своим аккаунтом и нужным доменом. Токен управления не нужно делать общим для всех пользователей.

  3. Настройте шлюз в Link

    Откройте «Подключение» → «Постоянный шлюз…». Введите домен, поддомен и токен. Link создаст туннель, отдельную DNS-запись и службы на VPS, затем проверит новый вход. После успеха адрес сохранится.

Для первой установки требуется уже работающий путь SSH до VPS, Linux x64 с systemd и права root. Если VPS полностью недоступен, сначала понадобится консоль хостера или другой административный канал. API-токен используется только во время настройки; на VPS остаётся отдельный токен конкретного туннеля.

Подобрать стратегию winws

Если встроенный WARP не соединяется, откройте «Стратегии». Здесь можно выбрать способ обработки его TLS-запросов. Если всё работает, менять стратегию необязательно.

Без редактирования конфигурации

  1. Выберите сервер. Для него должен быть включён встроенный WARP. Доступны шесть встроенных вариантов; базовый сохраняет поведение 0.3.1.
  2. Обновите каталог, если нужно. Выберите источник Flowseal · zapret-discord-youtube и нажмите «Обновить с GitHub». В списке появятся совместимые варианты general, ALT, FAKE TLS. bol-van остаётся альтернативным источником. Эта кнопка не меняет действующий мост и сохранённую стратегию.
  3. Подготовьте проверку. Сначала отключите профиль AmneziaVPN, затем мост Link. Внешние winws/zapret и системный WARP тоже должны быть остановлены. При таком отключении интернет может временно пропасть. Не делайте это во время удалённого сеанса, который зависит от VPN.
  4. Проверьте варианты. Откройте раздел от администратора. Нажмите «Проверить выбранную» или «Подобрать автоматически». Подбор начинается с выбранного варианта и идёт по кругу до первого успешного ответа VPS, до 25 секунд на вариант. Его можно отменить.
  5. Сохраните результат. Нажмите «Использовать для сервера», затем подключите Link и включите AmneziaVPN. Проверьте интернет. Успешный тест стратегии подтверждает путь до VPS и SSH-ключ, но не работу всего VPN.

Программа сама не останавливает другие VPN или winws. Для первого подбора нужна уже созданная регистрация WARP: она выполняется при обычном подключении с подтверждением условий Cloudflare. Если подбор не помог, прежняя настройка останется сохранённой.

Как вернуться назад?

«Вернуть базовую» сохраняет для сервера исходный вариант VPSLink. «Предыдущий каталог» возвращает предыдущую версию загруженного каталога; стратегия, сохранённая для сервера, от этого не меняется. Сначала остановите мост перед изменением стратегии.

Что именно скачивается с GitHub?

Совместимые TLS-параметры и шаблоны пакетов из Flowseal/zapret-discord-youtube либо пример bol-van, в зависимости от выбранного источника. Стратегии Flowseal применимы шире названия репозитория; в VPSLink они обрабатывают соединение WARP через TCP 443. Скачанные BAT/CMD не исполняются, winws и драйверы этой кнопкой не обновляются. Варианты, требующие TCP timestamps, пока пропускаются: программа не меняет эту системную настройку. Причины пропусков показаны под каталогом.

Обновление Link

Удалять приложение не нужно. Новый установщик обновляет существующую копию и сохраняет серверы, ключи и VPN-профили. После обновления подключение остаётся ручным.

В разделе «Обновления» приложение проверяет релизы JOOOOOJA/VPSLink на GitHub, включая предварительные версии Proof of Concept. Установка начинается только по вашему нажатию.

  1. Скачайте обновление при работающем интернете. Link проверит размер и SHA-256.
  2. Отключите VPN в AmneziaVPN, затем мост Link.
  3. Нажмите «Установить и закрыть Link» и подтвердите запрос Windows.
  4. После установки откройте Link, нажмите «Подключить» и включите прежний профиль AmneziaVPN.

Подключение после включения компьютера

Обычно достаточно открыть Link, выбрать сервер и нажать «Подключить». Дождитесь готовности моста, затем включите сохранённый профиль в AmneziaVPN. Для отключения сначала выключите VPN в AmneziaVPN, затем мост в Link.

Автозапуск — по желанию

Для обычного подключения эти настройки не нужны. Проверка автоподключения после перезагрузки в версии 0.3.1 пока не завершена.

Остановите Link, откройте «Серверы» → «Изменить», включите дополнительные настройки и перейдите в «Дополнительные параметры».

  1. Включите «Подключать этот сервер при запуске Link».
  2. Включите «Запускать Link при входе в Windows».
  3. Включите «Запускать AmneziaVPN после готовности моста».
  4. Укажите номер уже импортированного сервера в AmneziaVPN, начиная с 1.
  5. Отключите отдельный автозапуск AmneziaVPN, чтобы её запуском управлял Link.

Задача Windows запускает Link после входа в вашу учётную запись. Пароль Windows в ней не сохраняется. Если интернет появляется с задержкой, Link повторяет подключение. Уже запущенную AmneziaVPN он не закрывает.

При смене папки установки откройте настройки автозапуска заново в новой копии Link. Автозапуск не означает автоматический вход в Windows. При USB-модеме телефон должен сначала выдать компьютеру сетевой адрес.

Если что-то не работает

Сервер готов, но сайты не открываются

Убедитесь, что включён именно профиль с адресом локального моста Link. Откройте «Диагностика» и выполните проверку интернета. После длительной остановки Link переподключите профиль AmneziaVPN. Внешний адрес WARP должен оставаться исключённым из внутреннего VPN — Link добавляет это исключение при экспорте профиля.

На компьютере уже работает другой VPN или WARP

Другой системный VPN может блокировать трафик AmneziaVPN своими фильтрами даже при правильных маршрутах. Не отключайте действующее рабочее соединение, если через него идёт удалённый доступ. Сначала проверьте Link в изолированной среде и подготовьте независимый канал управления.

Браузер показывает ошибку прокси

Проверьте браузерное расширение и системный прокси. Проверка интернета в Link выполняется без HTTP/SOCKS-прокси браузера, поэтому помогает отличить проблему VPN от проблемы браузера.

После перезагрузки USB-модем не даёт интернет

Проверьте интернет и режим USB-модема на телефоне. Адрес вида 169.254.x.x означает, что Windows не получила адрес от модема. Link ждёт появления рабочего маршрута. В виртуальной машине не передавайте USB на хост, если это нарушит его подключение.

Нужны права администратора

Встроенный winws использует драйвер WinDivert. Разрешите повышение прав для Link. Это нужно для запуска его сетевого компонента; отдельные установленные WARP и zapret приложение не должно останавливать.

Постоянный шлюз не настроился

Проверьте Active у домена, права API-токена, свободное имя поддомена и работающий SSH-вход. Повторите настройку с тем же профилем. Link не заменяет чужую DNS-запись и активирует новый адрес только после проверки.

Что делает тестовый профиль

В разделе диагностики можно сохранить отдельный профиль, который направляет через VPN только 1.1.1.1. Это помогает проверить туннель без перенаправления всего IPv4-трафика. Для обычной работы нужен основной профиль.

Профили и данные

Настройки находятся в %LOCALAPPDATA%\ThingsNotFun-Link. Учётные данные SSH и сохранённые конфигурации VPN защищены Windows DPAPI и привязаны к вашей учётной записи. Экспортированный .conf содержит приватный ключ: храните его как пароль и не включайте в диагностические отчёты.

Удаление приложения сохраняет личные профили. Удаление профиля в Link не удаляет созданного клиента на VPS. Для переноса на другой компьютер заново введите учётные данные: зашифрованные значения DPAPI не являются переносимой резервной копией.

Встроенный WARP — отдельная регистрация устройства Cloudflare. В комплект входят usque и winws; их лицензии находятся рядом с программой. Инструкция не отправляет данные в сеть; внешние ссылки открываются только по нажатию.
