VPSLink — подключение к своему серверу VPN

Установка добавит Link, встроенное ядро WARP (usque), winws и драйвер WinDivert в папку приложения. Драйвер используется только при запуске встроенного подключения с правами администратора.

Установщик подходит для Windows 10 x64 начиная с 21H2 (сборка 19044) и Windows 11 x64. Если совместимый .NET Desktop Runtime отсутствует, установщик добавит включённую в комплект версию 10.0.15. SSH-клиент входит в комплект и работает из папки VPSLink.

AmneziaVPN устанавливается отдельно. Для работы нужны собственный VPS с SSH и AmneziaWG либо приглашение от владельца такого сервера. Link создаёт клиентский профиль на этом VPN.

Установщик не подключает VPN автоматически. Настройка сервера и регистрация WARP выполняются в интерфейсе Link.

Профили и ключи сохраняются в локальной папке текущего пользователя. Обновление и удаление программы сохраняют эти данные. При удалении отключается автозапуск только установленной копии Link.

После установки откройте вкладку «Инструкция» — там есть короткие шаги и полная справка для браузера.
